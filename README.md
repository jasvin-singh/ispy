# iSpy Animations — Dual Theme Website

This GitHub Pages build contains two complete visual modes:

- **Dark theme (root `/`)** — preserves the original iSpy website design and remains the canonical/indexable version.
- **Light theme (`/light/`)** — editorial light design based on the Time 2 Talk light website style.

A split circular theme control links each page to its matching page in the other theme. Normal navigation remains inside the selected theme.

## SEO / technical updates

- Unique titles and meta descriptions
- Canonical URLs
- Open Graph / Twitter metadata
- JSON-LD structured data
- `robots.txt`
- `sitemap.xml`
- Favicon using the iSpy logo
- Semantic H1 coverage and iframe labels
- Repaired local media references
- Removed generic placeholder social URLs; verified LinkedIn remains linked
- Small-screen navigation safeguards for the preserved dark design

## Deploy to GitHub Pages

Upload **the contents of this folder** to the root of the repository that serves:

`https://jasvin-singh.github.io/iSpy/`

If the repository name or GitHub username changes, update the canonical base URL in the HTML files, `robots.txt`, and `sitemap.xml`.
